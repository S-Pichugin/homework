## Ключевые выводы

### System.arraycopy значительно быстрее:
- **Для малых массивов (1K-10K):** в 6-11 раз
- **Для средних массивов (100K):** в 1.7-4.9 раза
- **Особенно эффективен** при малых сдвигах (1-10 позиций)

### Для больших массивов (1M+):
- Разница минимальна (0.8-1.3x)
- В отдельных случаях manual loop показывает **сопоставимую** производительность
